# Kaylane TV

Kaylane TV is a Vega OS Fire TV web browser project optimized for 10-foot TV use, remote-control navigation, popup suppression, and a controlled browsing experience.

> Bootstrap note: this repository was initialized with this minimal commit so all subsequent project work can be developed and reviewed through branches and pull requests.

## Development policy

After this bootstrap commit, do not push feature work directly to `main`. All meaningful changes must go through a dedicated branch and pull request.
